# avahan
A Sports and Cultural Festival Management System for JK Group of Institutions.

## About

AVAHAN is the annual sports and cultural festival where colleges under the JK Group compete in various events.

The system will help manage:

- Colleges
- Events
- Participants
- Results
- Points
- Overall Champion

---

This project is being built as a learning journey to become a Full Stack Java Developer.
